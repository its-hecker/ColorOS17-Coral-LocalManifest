# ColorOS 17 for Pixel 4 XL (coral)

Maintainer: **Hecker**. Experimental **Android 17 ColorOS binary-port workspace** for Google Pixel 4 XL (`coral`).

The first milestone is a reproducible **offline input audit**, not a bootable release. Porting uses a separately obtained PLK110 ColorOS 17 GSI donor and the tested floral hardware base; OPPO/Google binary firmware is not stored here.

Development work is on `dev/coloros17-firstboot`. See that branch for pinned sources, donor inspection, verification scripts and the feature integration plan. **Do not flash any stage-0 artifacts.**
